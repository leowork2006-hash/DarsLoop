# Authored synthetic lessons

The current public example is the five-pillars introduction in demo-five-pillars-script.txt, with demo-five-pillars-timing.json and demo-five-pillars.mp3. Basic definitions and scope are documented in ../RELIGIOUS-SOURCES.md. The voice, notes and practice are prepared examples, not a live ASR/model result or scholarly review. Regenerate with `node --import tsx scripts/make-demo-audio.ts` after installing eSpeak NG, FFmpeg and FFprobe. Timing uses each natural audio segment without time stretching.

Legacy demo-script.txt, demo-timing.json and demo.mp3 are retained so previously seeded study-habits examples keep matching their own recording. No real teacher/student data is included.

Original script and rendered audio are project-created. eSpeak NG is GPL-3.0; no speech-engine code or voice model is bundled. Its output licence only applies when the output itself is a covered work. See https://espeak.sourceforge.net/license.html .
